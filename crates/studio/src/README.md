# qd-studio source

The review studio as data: the widgets an AI agent may use to explain a pull request (a lead and pages of sections, callouts, code excerpts and comparisons, tables and traces, a scope, a reading order, graphs and sequences), the code anchors that tie them to lines of the diff, and the checks that drop a widget whose anchor the diff does not show. It also writes what the agent is given (a numbered listing of the diffs, the JSON Schema of the answer, the authoring guide) and prepares a shallow checkout of the two commits (`base/`, `head/`, `change.diff`) and runs Claude Code headless and confined in it with read-only tools, following its event stream for progress. It does not draw anything, call the GitHub API or store studios; the app gives it the loaded diffs and renders the result.

It also defines and validates smart review buckets: any number of ordered, described groups covering all changed paths, with optional suggestions to mark a mechanical group viewed. Folder selectors expand once into exact files. The smart-filter prompt shares the file inventory and budgeted diff listings with briefs; its separate schema and guide run with explicit Opus/high effort and only Read, Grep and Glob.
