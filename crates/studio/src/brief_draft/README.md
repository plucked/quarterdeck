# Brief drafts

A Brief is authored privately through complete page replacements over one frozen
set of citable diff lines. The strict page path reuses the ordinary parser's
widget and diagram checks, but rejects any page that would lose a widget, scope
entry or table row. Legacy stored and one-shot artifacts remain readable through
the tolerant parser. Tour links retain their existing start-line semantics.

Page identity is independent of reading order. Finishing requires a lead and an
explicit order of one to ten accepted pages, then seals the typed studio and the
complete accepted wire artifact under the same receipt. Transport owns JSON
request dispatch and paginated reads; the host owns cancellation, process success
and atomic publication. Resource bounds apply to bytes, not repair attempts or
model spend.
