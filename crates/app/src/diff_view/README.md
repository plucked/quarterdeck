# diff_view

Draws what `qc-diff` and `qc-syntax` built for each changed file, one row at a time so the detail pane can virtualize: a file's header (status, path, line counts, a viewed checkbox), hunk headers, and unified or side-by-side rows with line numbers, syntax colors and marked changes, wrapping or clipped to a sideways offset. Each row draws its piece of the file's bordered card. Also draws the quiet summary bar above the files; the options themselves live in the settings window. It does not parse patches, fetch files or keep any state: the detail view decides which rows exist, owns collapsed, viewed and scroll state and the settings, and passes handlers for changing them.
