# review_queue

The main window's view: the viewer's own pull requests, those that request their review, and others' open pull requests in the watched repositories (one tab each, grouped by repository, with a stack's layers grouped under its header), which one is selected, and when the lists refresh from GitHub. The Others tab lists every watched repository, each with a filter that opens under its header; filtering happens here, on the fetched list, so changing a filter costs no request. It hands the selected pull request to `pull_request_detail`, which shows it, and opens the stack layers the detail asks for, fetching one that is in no list; it does not load files or draw diffs. It also draws the bar across the window's top (panel toggles, tabs, refresh) and decides what stays selected across refreshes and relaunches. Which repositories are watched is a preference, changed in the settings window.
