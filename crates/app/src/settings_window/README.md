# settings_window

The window opened with cmd-, that holds every preference, one category per page: Appearance (the theme and optional folder heatmap, with previews), File Diff, GitHub (the account, the cache, API usage), Repositories (the repositories the Others tab lists), Filters (the branch patterns every queue tab hides) and Updates (the version, the update status, what's new). It shows and changes the preferences through `AppSettings`, which saves them and tells the views that use them; it keeps no preferences of its own. Signing in saves the token through `qd-github` and restarts the app; the Updates page only shows and drives the `AppUpdater`. Only one settings window is open at a time.
