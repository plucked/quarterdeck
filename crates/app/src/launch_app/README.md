# Launch app

Starts Quarterdeck: opens the database and the services, starts gpui, registers the app's commands and fonts, and opens the main window where it was last placed, hidden behind the startup splash while its movie plays (or at once without it). The command-line option `--no-splash` opens the main window immediately, without playing the movie or fading in. When the database cannot be opened, it says why in a system alert, since an app started from Finder has no terminal. It does not draw any window itself; the main window, the splash and the brief gallery live in their own folders.

For UI tests and visual checks, launch with `--no-splash` before attaching automation. After quitting, do not query the stopped app through UI automation: attaching or requesting its state can relaunch it without arguments. Start the development bundle explicitly with the flag, confirm only one development instance is running, then reconnect. Omit the flag only when testing the splash, playback, or fade itself.
