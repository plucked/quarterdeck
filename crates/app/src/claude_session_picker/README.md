# Claude session picker

An inline destination picker for a snapshot of local review notes. It discovers active Claude sessions when opened or refreshed, then presents a full-width virtualized list with prominent names, compact folder labels and quiet activity indicators. Repository and branch metadata arrive after the list appears, from at most four background lookups at once and one per unique directory. The completed metadata groups sessions by main checkout, with alphabetic repository headings and matching session counts. Linked worktrees share a heading; independent clones with the same name show their paths. Other sessions appear last. Grouping applies once, preserving the chosen destination. The branch precedes the folder in its row, and appears in the full hover details. Non-Git folders and detached HEAD keep their folder label. Search matches every typed term across names, repositories, branches, full paths and session IDs. Duplicate names receive a short ID hint; hover reveals full details. The list fills the remaining side-panel height between fixed search controls and the send footer, growing and shrinking with the window. The note preview is hidden while the picker is open and restored when closed. The viewport contains 32 px headings and 54 px session rows, virtualized together, with 216 px of measurement beyond the viewport so wheel events can reach later rows, and exact row heights for scrollbar sizing and revealing unmeasured destinations. Search omits empty headings and updates each count. Arrow keys skip headings and follow the grouped visible matches, and Enter submits only after explicit selection. A hidden selection is cleared when filtering, and refresh always clears the destination.

The chosen name and path remain above the send action, which names the note count. Sending and success replace the list with a compact receipt; sending to another session starts a fresh explicit selection. The session library refreshes and validates again before sending. This view owns asynchronous progress and feedback; it never edits notes or Claude settings. The detail pane closes it when the notes or review scope change so a stale review cannot be sent.

A headless gpui regression sends pixel and line wheel events through the production list configuration, checking that mixed-height repository groups scroll to the bottom and back. It uses no Claude sessions or application data.
