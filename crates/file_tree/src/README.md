# qd-file-tree source

Turns a pull request's changed file paths into the folder tree the review pane shows: folders before files, sorted by name, chains of single folders joined into one node, and the depth-first order the diff then follows so both agree. It also decides which files the filter shows: a viewed switch and two chip rows, one by kind (code, tests, generated, moved) and one by file type, where every file falls in exactly one chip per row; it judges tests and generated files from path conventions because GitHub does not say. It also picks each file's icon from its name and extension (which picture that is, is the app's concern). It renders nothing and knows nothing about viewed marks or moves beyond the flags it is given.
